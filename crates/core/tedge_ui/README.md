# tedge-ui

## What is this project?

This is a PoC to host a webpage on localhost.

Supported and planned features:
- tedge config UI (fully supported)
- Web terminal (planned, currently fake terminal)

## Serving tedge-ui App with Dioxus

Run the following command in the root of the `thin-edge.io` repository:

```bash
dx serve --package tedge-ui
```

Note: You need to install the [Dioxus CLI](https://dioxuslabs.com/learn/0.7/getting_started/) first.
